# Problem practice by topic

Problem statements are hosted on LeetCode; use their links, not copied proprietary content.

For every solved problem, create a Python file containing your own solution and a brief explanation. Add a relevant unit test in `tests/` and record the attempt in `progress.csv`.

The folders start with `.gitkeep` files because no solutions have been completed yet. This is intentional.
